\# IPL Cricket Performance \& Strategy Analysis (2008–2024)



\## Project Overview

An end-to-end SQL data analysis project investigating 16+ seasons of Indian Premier League (IPL) matches. Using relational database modeling and analytical SQL queries, this project explores team dominance, toss dynamics, venue biases, and individual player performance benchmarks.



\## Dataset

\- \*\*Source:\*\* Kaggle IPL Complete Dataset (2008–2024)

\- \*\*Tables:\*\*

&#x20; - `matches`: Match-level metadata (teams, toss decisions, winners, venues).

&#x20; - `deliveries`: Ball-by-ball records (batter runs, extras, wickets, bowler stats).



\## Key Insights

1\. \*\*Team Dominance:\*\* Mumbai Indians and Chennai Super Kings lead in all-time win tallies.

2\. \*\*Toss Impact:\*\* Teams winning the toss hold an overall win rate of \~51–53%, showing a slight statistical advantage.

3\. \*\*Chasing Bias:\*\* Electing to field first yields higher win rates, especially at dew-affected grounds like Wankhede Stadium and Eden Gardens.

4\. \*\*Scoring Trends:\*\* Average runs per ball and total season aggregates show a strong upward trajectory over the years.

5\. \*\*Bowling Economy:\*\* Benchmarked the top economy rates for high-volume bowlers (min. 100 overs bowled).



\## Tech Stack

\- \*\*Database:\*\* MySQL 9.x / MySQL Workbench

\- \*\*SQL Skills:\*\* Multi-table `JOIN`, Aggregations (`SUM`, `AVG`, `COUNT`), `CASE` conditional statements, `HAVING`, Grouping.
